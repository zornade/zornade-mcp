Zornade MCP

Model Context Protocol server for Italian cadastral data: 85 million parcels with OMI valuations, hydrogeological and seismic risk, subsidence, solar potential and planning constraints. Six read-only tools, no writes anywhere. Powered by the Zornade API v2.

Endpoint

https://mcp.zornade.com/mcp

Streamable HTTP, protocol revision 2025-06-18. Server version 1.2.0. Listed in the official MCP Registry as io.github.zornade/zornade-mcp.

Authentication

Two ways in, and you only need one.

OAuth 2.1, for clients that support it (Claude, Cursor, VS Code). No key to paste: the server mints a personal API key on first connection and stores only its hash. Protected resource metadata at /.well-known/oauth-protected-resource.

API key, for everything else. A free key (zrn_..., from app.zornade.com/api) goes in the x-api-key header, in Authorization: Bearer, or in the ?api_key= query parameter.

Tools

zornade_geocode_search   Forward geocoding on ANNCSU street data
zornade_geocode_reverse  Reverse geocoding from coordinates
zornade_parcel_by_id     Enriched parcel profile: cadastral, OMI, risk, solar
zornade_parcel_locate    Parcels by point(s) or bounding box
zornade_parcel_search    Parcels by comune, foglio and parcel label
zornade_admin_lists      Regions, provinces and municipalities

All six are annotated readOnlyHint: true and idempotentHint: true, so clients can call them without asking for confirmation on every step.

Connect

Claude Code, with a key:

claude mcp add zornade -t http https://mcp.zornade.com/mcp \
  --header "x-api-key: zrn_YOUR_KEY"

Claude Desktop and Cursor, with OAuth: add the URL and sign in when asked.

https://mcp.zornade.com/mcp

Test

curl -X POST https://mcp.zornade.com/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "x-api-key: zrn_YOUR_KEY" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Cost and licence

The server and the API are free with the attribution «Dati elaborati da Zornade» visible in your product. The commercial licence removes that one line and nothing else: source attributions (Agenzia delle Entrate, ISTAT, ISPRA, INGV, Copernicus) stay mandatory, and the rate limit does not change. 

Free                    10.000 requests/hour, attribution required
Licenza API             490 EUR/year per company
Licenza visura-api      990 EUR/year per company
Continuita Base         1.800 EUR/year, first response in 1 business day
Continuita Ops          4.800 EUR/year, first response in 4 business hours

Priced per company, never per user and never per call. The support contract is a written response time with an S1-S4 severity matrix and service credits, not an uptime promise.
